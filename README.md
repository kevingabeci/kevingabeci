# Hey, I'm Kevin Gabeci

**Software Engineer** focused on backend systems and full-stack development, mostly in Python and Django with React and TypeScript on the front. Started with a C# desktop app, now building AI platforms, payment infrastructure and my own SaaS products. Strong backend foundation with an eye for clean design.

- Testing local AI models on my Mac and writing up what actually holds up
- Building and running my own SaaS products
- Making videos about all of it on [Kevin Gabeci Labs](https://www.youtube.com/@kevingabecilabs)

## Featured Project

### Brain OS, my private Jarvis

My own AI operating system, and the thing I use every single day. It works alongside me on everything:

- remembers everything for me, from people and decisions to deadlines
- keeps my tasks and reminders, and nudges me when something slips
- drafts my messages and helps me prepare for meetings and interviews
- runs my content publishing and outreach on autopilot
- keeps an eye on my sites and products
- coordinates the AI agents that code and research with me

It's private, and it runs on my own server.

## Agent-Ready

My site talks to AI agents. [kevingabeci.com](https://kevingabeci.com) serves [llms.txt](https://kevingabeci.com/llms.txt), registers WebMCP tools in the browser, and runs an MCP endpoint your agent can call to look up my projects and how to reach me:

```bash
claude mcp add --transport http kevin https://kevingabeci.com/api/mcp
```
